# V3 UI status

The current pass compacts Home and Energy. Home uses a 102 px climate card, two 50 px metric cards, and 52 px quick controls. Energy keeps its status, summary, and history in separate surfaces and moves the chart closer to the top. The existing four-tab navigation and LVGL theme remain the starting point for the full redesign.

Visual acceptance is pending. Check all seven screens with long names, maximum numeric values, offline data, and open dialogs. Validate clipping, overlap, icons, scroll reachability, navigation visibility, and touch targets in a 480 × 480 rendering of the production widgets.
